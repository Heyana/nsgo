`ui.Switch` — это настройка, которая вступает в силу сразу. Он не хранит значение: им владеет приложение, которое обновляет его в `OnChange`.

```go preview=switch/basic
notifications := core.NewSignal(cx, true)
ui.Switch{Checked: notifications.Get, OnChange: notifications.Set, Label: "Notifications"}
```

## Размеры

`ui.Switch` принимает `Checked`, `OnChange`, `Label` и `Size` (`SizeDefault`, `SizeSmall` или `SizeLarge`). Бегунок скользит, а дорожка меняет цвет по кадровым часам платформы.

```go preview=switch/small
ui.Switch{Checked: sync.Get, OnChange: sync.Set, Label: "Sync automatically", Size: ui.SizeSmall}
```

Переключатель предназначен для настройки, которая применяется сразу. Для выбора внутри формы используйте [флажок](checkbox.md); для одного из нескольких вариантов — `ui.Radio` в `ui.RadioGroup` или [выпадающий список](select.md).

## Доступность

Переключатель сообщает `RoleSwitch` и своё состояние — включён или выключен. `Label` — то, что зачитывают вспомогательные технологии; обычно меткой служит текст рядом с переключателем. Когда переключатель в фокусе клавиатуры, его переключают пробел или нажатие.

## Платформы

Элемент управления по умолчанию рисует приложение, поэтому он везде выглядит одинаково. `Variant: ui.SwitchSystem` запрашивает платформенный элемент: NSSwitch на macOS, UISwitch на iOS и переключатель Material 3 размером 52 × 32 dp на Android. Остальные платформы используют вид по умолчанию. Нажатия, фокус и программа чтения с экрана — платформенные. Переключатель по умолчанию на телефоне намеренно того же размера, что и на десктопе; `SizeSmall` предназначен для плотных строк, а не для конкретного устройства.
