`core.Scroll` — собственная область прокрутки платформы. Её дочерние элементы располагаются в столбец или, с `Horizontal`, в строку, и она заполняет свой контейнер, пока прокручивается содержимое.

```go preview=scroll/basic height=240
core.Scroll{Style: core.Style{FlexGrow: 1}, Children: []core.Node{
	core.View{Style: core.Style{Padding: core.All(16), Gap: 12}, Children: rows},
}}
```

Отступы задаются у содержимого, а не у области прокрутки, чтобы полоса прокрутки оставалась у края. Область прокрутки сжимается, чтобы поместиться в родителе, если в её стиле не указано иное. Задайте `NoShrink`, когда она должна сохранять запрошенный размер, пока сжимается соседний элемент.

## Поведение

`Behavior` выбирает способ прокрутки: `Paging`, `SnapToInterval` или `SnapToOffsets` с `SnapToAlignment`, `DecelerationRate`, `NoBounces`, `ContentInset` и правила клавиатуры.

```go preview=scroll/paging height=240
core.Scroll{
	Behavior: core.ScrollBehavior{
		Paging:                    true,
		KeyboardDismissMode:       core.KeyboardDismissOnDrag,
		KeyboardShouldPersistTaps: core.KeyboardTapsHandled,
	},
	Children: pages,
}
```

`HideIndicator` скрывает полосу прокрутки платформы, а `Bar` рисует собственную полосу приложения. `MinZoomScale` и `MaxZoomScale` позволяют масштабировать щипком; `NoPinchZoom` их игнорирует. `CenterContent` центрирует содержимое, которое меньше видимой области.

## Обновление и события

`OnRefresh` делает область обновляемой; задавайте `Refreshing`, пока идёт работа. `PullValue` следит за тем, насколько вытянуто содержимое, — для собственного индикатора приложения, а `Behavior.RefreshIndicator` задаёт его высоту.

```go
refreshing := core.NewSignal(cx, false)
core.Scroll{
	Refreshing: refreshing.Get,
	OnRefresh:  func() { refreshing.Set(true); reload(cx) },
	Children:   content,
}
```

`OnScroll` сообщает смещение не чаще раза за ход или раза за `ScrollEventThrottle`; `Stale` помечает событие, предшествующее применению платформой прокрутки из кода. `OnScrollDragStart`, `OnScrollDragEnd`, `OnMomentumStart`, `OnMomentumEnd` и `OnScrollEnd` обрамляют жесты пользователя.

`OffsetValues` следит за смещением в главном потоке — для заголовка, который сворачивается без фиксации изменений на каждом кадре. `Ref` прокручивает из кода с помощью `ScrollTo`, `ScrollToEnd` и `ZoomTo`, а ссылка на любое представление внутри показывает его через `Reveal`, прокручивая все окружающие его области прокрутки:

```go
row.Reveal(core.RevealOptions{Vertical: core.ScrollAlignCenter, Animated: true})
```

`RevealBox` вместо этого показывает прямоугольник внутри представления, например прямоугольник слова из `TextRangeBoxes` текста, а `Margin` оставляет свободное место у краёв самой внешней области прокрутки для панели поверх неё.

Представление, на которое клавиатура переводит фокус, само прокручивается в видимую область.

## Раскладка

`Horizontal` прокручивает поперёк. `Behavior.ContentInset` добавляет вокруг содержимого место, которое прокручивается вместе с ним. Для страницы, заполняющей безопасную область, используйте `PaddingEnv` у содержимого, а не у области прокрутки.

## Доступность

`Label` задаёт имя области прокрутки, а `Role` сообщает, чем она является, например списком (list box). Жесты прокрутки платформы, прокрутка с клавиатуры и прокрутка программой чтения с экрана сохраняются; `Busy` сообщает о представлении, которое ещё загружается.

## Платформы

Каждый бэкенд использует область прокрутки платформы, поэтому инерционная прокрутка, отскоки, полосы прокрутки и сенсорная прокрутка нативные. Эффекты на краях различаются: macOS и iOS пружинят, Android растягивает, Windows и Linux останавливаются, а веб следует за браузером. `EdgeEffects` и `EdgeBar` добавляют панели поверх содержимого там, где это нужно приложению. На телефонах и планшетах с iOS и Android переполненные вертикальные и горизонтальные области прокрутки показывают вдоль активной оси маркер прокрутки, который можно перетаскивать касанием по всему диапазону содержимого; короткие области прокрутки, помещающиеся без переполнения, масштабируемые представления, `Behavior.NoScroll`, `HideIndicator` и представления с собственным `Bar` или `base.SetScrollbarTheme` его скрывают. В тестах `nsgotest.App.ScrollHandle` сообщает границы его видимой области, а `DragAt` или `Touch` перетаскивают его напрямую. В Windows накладной индикатор появляется при прокрутке колесом, касанием, перетаскивании полосы и их инерции, но не при принадлежащих приложению `ScrollTo`, `ScrollBy`, показе элементов, отступах или анимациях.
