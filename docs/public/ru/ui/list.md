`ui.List` отрисовывает строки в нативной области прокрутки и создаёт только строки рядом с экраном, поддерживая выделение, активацию и клавиатуру.

```go preview=list/basic height=280
ui.List{
	Count:         func() int { return len(items) },
	Key:           func(i int) any { return items[i].ID },
	EstimatedSize: 44,
	Row: func(cx *core.Scope, row core.ListRow) core.Node {
		item := items[row.Index()]
		return ui.Text(item.Title, 13, ui.Regular, colors.Text)
	},
}
```

## Строки и идентичность

`Count` сообщает, сколько строк, а `Row` создаёт одну строку. `Key` задаёт строке идентичность: оставшиеся строки сохраняют свои ячейки и состояние, когда строки над ними появляются и исчезают. Используйте идентификатор, а не индекс, если строки можно добавлять, удалять или переупорядочивать; индекс — это сигнал, который следует за ячейкой, когда она показывает другую строку.

```go
ui.List{Count: count, Key: func(i int) any { return items[i].ID }, Row: func(cx *core.Scope, row core.ListRow) core.Node {
	return ui.Text(items[row.Index()].Title, 13, ui.Regular, colors.Text)
}}
```

`EstimatedSize` — ожидаемая высота строки, 50 пунктов, если 0. Строки могут иметь разную высоту; список измеряет созданные строки и оценивает остальные.

## Раскладка

`Header`, `Footer` и `Empty` содержат содержимое вокруг строк и на время, пока строк нет. `Gap` разделяет строки, `Columns` располагает их рядом, а отступы списка относятся к содержимому, поэтому полоса прокрутки остаётся у края. Задайте списку высоту или позвольте ему заполнить родителя.

## Выделение и активация

`ui.List` принимает `Selection`, созданный с помощью `ui.NewSelection(cx, multiple)`. Ключи, метки, активация и клавиатура следуют за ним: Up, Down, Home и End перемещают курсор, Shift расширяет выделение, Mod+A выбирает всё, пробел переключает строку при множественном выделении, а Enter или двойной щелчок активирует строку.

```go preview=list/selection height=320
selected := ui.NewSelection(cx, true)
ui.List{
	Count: count, Key: func(i int) any { return items[i].ID },
	Selection: selected,
	OnActivate: func(i int) { open(items[i]) },
	RowLabel:   func(i int) string { return items[i].Title },
	Row: func(cx *core.Scope, row core.ListRow) core.Node { return rowContent(cx, items[row.Index()]) },
}
```

`OnSelectionChange` выполняется после того, как нажатие, клавиша или поиск по первым буквам меняет выбранные строки, и не выполняется, когда приложение само задаёт `Selection`, поэтому панель подробностей может следовать за выбором пользователя, пока приложение переводит выделение на элемент, открытый иным способом.

`TapSelects` заставляет касание на телефоне выделять строку, а не активировать её. `RowLabel` — это то, что зачитывают вспомогательные технологии и с чем сопоставляется поиск по первым буквам.

## Загрузка и прокрутка

`OnLoadMore` выполняется при приближении к концу, один раз на каждое число строк. `Ref` прокручивает с помощью `ScrollToIndexAt`, `ScrollToEnd` и `ScrollToIndex`. У `core.List` — простого списка, лежащего в основе, — также есть `OnLoadMoreAtStart`, `Inverted` для чата, `StickyHeaderIndices`, `MaintainVisibleContentPosition`, `Viewport` и `ViewabilityConfig` для низкоуровневых случаев ([Списки и прокрутка](../lists.md)).

## Доступность

Список — это один список или listbox с именем из `Label`, а имя строки — её текст или `RowLabel`. Список с выделением сообщает строку курсора и озвучивает её при перемещении с клавиатуры. Когда программа чтения с экрана выходит за пределы видимой области, она просит список прокрутиться туда, и список создаёт строки, до которых она доходит.

## Платформы

Нативная область прокрутки и виртуализация одинаковы на каждой целевой платформе. Строки переиспользуются, поэтому состояние строки должно следовать за её `Key`; обычное правило — хранить состояние в приложении, а не в строке.
