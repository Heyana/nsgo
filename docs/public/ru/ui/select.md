`ui.Select[T]` выбирает одно из списка значений любого сравнимого типа. Список открывается под триггером на любом устройстве; `Presentation: base.PresentSheet` вместо этого открывает его как панель снизу, что может понадобиться приложению для телефона.

```go preview=select/basic height=280
size := core.NewSignal(cx, "m")
ui.Select[string]{
	Options: []ui.Option[string]{{Value: "s", Label: "Small"}, {Value: "m", Label: "Medium"}, {Value: "l", Label: "Large"}},
	Value:   size.Get,
	OnChange: size.Set,
	Label:   "Size",
}
```

## Варианты и поиск

`Options` — это значения `ui.Option[T]`, каждое с `Value`, `Label` и необязательными `Group`, `Icon`, функцией `Disabled` или собственным `Content` приложения. Соседние варианты с одной непустой `Group` показываются под её заголовком — в `Select` или `Combobox`; клавиши со стрелками и ввод текста его пропускают, а программы чтения с экрана зачитывают его как заголовок. Используйте `OptionsFunc`, когда варианты следуют за сигналом: тогда открытый список обновляется на месте, сохраняя значение и фокус поля. `Placeholder` показывается, пока ни один вариант не выбран. `Searchable` фильтрует список по вводу, `OnClear` показывает кнопку очистки, а `Disabled` отключает выпадающий список.

```go preview=select/searchable height=400
ui.Select[string]{
	Options:  languages,
	Value:    language.Get,
	OnChange: language.Set,
	Searchable: true,
	SearchPlaceholder: "Search languages",
	OnClear:  func() { language.Set("") },
	Placeholder: "Choose a language",
}
```

`Style` задаёт раскладку выпадающего списка — шириной 200 пунктов, если в нём не задана ширина; его высота, отступы и шрифт передаются полю, как у [Input](input.md), поэтому выпадающий список выравнивается с кнопкой `SizeSmall`:

```go
ui.Select[string]{Options: sizes, Value: size.Get, OnChange: size.Set, Label: "Size",
	Style: core.Style{Height: core.Pt(ui.SizeSmall.Height()), FontSize: 12}}
```

## Поведение

Up, Down, Return и пробел открывают список с триггера в фокусе; стрелки перемещают подсветку, а поиск по первым буквам переходит по заголовкам пунктов. Выбор пункта закрывает список и сообщает его значение. Escape, «назад» и нажатие снаружи закрывают список без изменений. `Empty` — текст, который показывается, пока поиск ничего не находит.

## Доступность

`Label` задаёт имя поля для вспомогательных технологий. Используйте `LabelFunc`, чтобы обновлять это имя на месте при изменении его сигналов. При пустой метке используется `Placeholder`. Триггер и список несут роли выпадающего списка, а выбранный пункт сообщается. Клавиатура достигает триггера клавишей Tab и открывает его клавишей Return или пробелом.

## Платформы

В macOS, Windows и Linux список — всплывающее окно рядом с триггером. В iOS и Android это панель, а выбранная строка остаётся в поле. Одни и те же варианты и значения работают на каждой целевой платформе.
