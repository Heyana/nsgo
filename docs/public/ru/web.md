## Сборка приложения

```sh
go tool nsgo build -target web
```

Раздавайте сгенерированный каталог по HTTP. Имена ресурсов релиза содержат хеши содержимого, поэтому кешируйте их как неизменяемые; `index.html`, `nsgo.json` и `manifest.webmanifest` проверяйте повторно. Веб-приложение сохраняет поведение раскладки, прокрутки, фокуса и указателя NSGo.

## Заголовки и ссылки

`core.View` или `core.Text` с `Role: core.RoleHeader` становится элементом от `h1` до `h6`, который выбирается по `AccessibilityLevel`; без уровня это `h2`. Заголовки Markdown из `base/textview` несут свои уровни. Поля и шрифты заголовков браузера не меняют оформление приложения.

`base.Link` и `ui.Link` публикуют свой `Href` как якорь. Обычный щелчок запускает `OnOpen` и `OnPress` приложения; щелчок средней кнопкой или щелчок с модификатором использует действие ссылки браузера. Браузер предоставляет своё контекстное меню ссылки, если приложение не обрабатывает `OnContextMenu`. У отключённой ссылки нет активного адреса. Для собственного представления с ролью ссылки задайте `core.View.Web` равным `core.WebViewProps{Href: "/notes"}` или привяжите `HrefFunc`. В TSX используется `web={{href: "/notes"}}`; заголовки используют `accessibilityLevel={1}`. Небезопасные исполняемые схемы URL отклоняются. Ограниченное содержимое оставляет навигацию в своих ограниченных обработчиках нажатий и не объявляет браузерного адреса.

## Метаданные страницы

Импортируйте `github.com/nsgo-dev/nsgo/web` и поместите `web.Head` рядом с содержимым страницы:

```go
core.Group{
	web.Head{Title: "Notes", Description: "Your saved notes"},
	pageContent,
}
```

`TitleFunc` и `DescriptionFunc` следуют за сигналами. Более поздние видимые `Head` переопределяют заданные ими поля и наследуют остальные. Скрытие или удаление страницы восстанавливает более ранние `Head`; удаление всех `Head` восстанавливает исходный документ. Пустое статическое поле наследуется; функция, возвращающая пустую строку, очищает его. `Head` не добавляет узла раскладки. Нативные платформы, встроенные приложения и ограниченное содержимое не трогают документ своего хоста.

В TSX импортируйте `Head` из `nsgo/web` и напишите `<Head title={title()} description="Your saved notes" />`. Для статических HTML-превью пререндерите каждый URL в рамках развёртывания сайта; `Head` обновляет работающий документ.

## Раздача ресурсов с CDN

Загрузчик разрешает все файлы приложения относительно `nsgo.json`. Страница может загрузить приложение с другого источника (origin):

```js
const url = new URL("https://cdn.example.com/notes/nsgo.json");
const config = await (await fetch(url)).json();
const { mount } = await import(new URL(config.loader, url).href);
await mount(null, url.href, { config });
```

Разрешите источнику страницы получать файлы CDN через CORS и отдавайте WebAssembly как `application/wasm`. Отдавайте входной HTML приложения для всех глубоких маршрутов, которые использует приложение. В разделе [Встраивание](embedding.md#web) показано, как вместо этого смонтировать приложение в элемент.
