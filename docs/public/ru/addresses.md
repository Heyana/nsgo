`cx.AppURL()` считывает адрес приложения как отслеживаемое значение. В вебе исходный URL страницы доступен ещё до рендеринга корня, поэтому перезагрузка или переход по общей ссылке могут открыть то же самое представление. Приложение само решает, как сопоставлять URL со своими представлениями.

```go
func Root(cx *core.Scope) core.Node {
    return core.View{Children: []core.Node{
        core.Text{ContentFunc: cx.AppURL},
        base.Button{Label: "Open film", OnPress: func(core.PressEvent) {
            if err := cx.SetAppURL("/films/42", core.AppURLOptions{
                History: core.HistoryPush,
            }); err != nil {
                // Show the error in the app's usual way.
            }
        }},
    }}
}
```

`SetAppURL` немедленно обновляет отслеживаемый адрес без запроса страницы и без навигации по стеку. По умолчанию он заменяет текущую запись в истории браузера; `HistoryPush` добавляет новую запись. Если в том же коммите происходит переход навигации или показ модального экрана, новую запись создаёт именно он, чтобы одно действие не порождало два шага «Назад». При нескольких записях адреса за один коммит сохраняется последний адрес и любой запрос на добавление записи в историю (`HistoryPush`).

Относительные адреса разрешаются относительно текущего адреса либо явно заданного HTML-тега `base`. Адрес в браузере обязан оставаться на том же источнике (`origin`), что и страница. Некорректные адреса, пробельные символы, управляющие символы, обратные слеши и адреса длиннее 16 КиБ возвращают ошибку, не изменяя текущий адрес.

`cx.OnAppURLChange(func(change core.AppURLChange) { ... })` отслеживает переходы по истории браузера и редактирование хеша. Поле `change.Reason` принимает значения `"back"`, `"forward"` или `"address"`; возвращённая функция отменяет подписку, а уничтожение области (`Scope`) автоматически удаляет слушатель. Для получения исходного адреса используйте чтение `AppURL`. Собственные вызовы записи из приложения обновляют привязки, но не отправляют уведомление об изменении. Переход по истории, при котором адрес остаётся прежним, также не вызывает уведомления.

Кнопка «Назад» в браузере по-прежнему закрывает модальное окно или снимает экран из стека навигации. Если приложение отклоняет возврат назад, восстанавливается текущая запись истории и её адрес. Обработчик закрытия может задать собственный замещающий адрес. Программный возврат по стеку (`pop`) обновляет адрес после асинхронного перехода по истории, а записи адреса, поступающие во время этого перехода, ожидают его завершения. Выход назад за пределы записей текущего проигрывателя покидает приложение, включая записи, оставшиеся от предыдущей загрузки.

Для путей вида `/films/42` укажите каталог развёртывания приложения и настройте сервер так, чтобы для маршрутов приложения отдавался файл `index.html`:

```yaml
web:
  base: /        # /my-app/ when deployed below that directory
```

Параметр `web.base` записывает в HTML элемент `base`, благодаря чему скрипты, стили, Wasm и ресурсы продолжают загружаться при прямом открытии глубокого адреса. Без него сохраняются существующие относительные пути к ресурсам; адреса с query-параметрами или хешем могут работать с ними без изменений. Правила резервного перенаправления на сервере не должны перехватывать запросы к реальным ресурсам. Строгая политика Content Security Policy должна разрешать этот базовый URL того же источника (`base-uri 'self'`).

Приложение, встроенное в другую страницу, хранит свой адрес внутренне и не затрагивает историю содержащей его страницы. `iframe` того же источника может явно включить интеграцию с историей с помощью атрибута `data-nsgo-history`. Ограниченные (confined) поддеревья не могут читать или изменять адрес приложения.

На остальных целевых платформах `AppURL` хранит последнюю ссылку, которой было открыто приложение, либо значение, сохранённое через `SetAppURL`; изменение адреса не влияет на нативное окно или системный браузер. Мини-приложения также хранят это значение, не изменяя маршруты своего хоста.

В TSX используется то же состояние:

```tsx
import { UrlScheme } from "nsgo";

UrlScheme.url();
UrlScheme.setUrl("/films/42", { history: "push" });
const stop = UrlScheme.on("change", ({ url, reason }) => {
  // Update the app's route from the browser's choice.
});
```
