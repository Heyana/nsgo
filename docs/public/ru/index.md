NSGo — это кроссплатформенный фреймворк нативного UI, написанный на Go. Вы пишете приложение один раз, на Go или на TSX, и оно работает на iOS и в его App Clips, на tvOS, watchOS, Android, macOS, Windows, Linux и в вебе, отрисовываясь собственными представлениями каждой платформы. Приложения на Go также работают в мини-программах WeChat, QQ, Alipay и Douyin — экспериментально: платформы ограничивают приложение 2 МБ, что более крупные приложения превышают. HarmonyOS запускает приложения на Go в режиме предварительной версии, с отрисовкой через ArkUI.

## Что вы пишете

Приложение — это пакет main на Go. Его компоненты возвращают элементы: представления, текст, изображения, поля ввода и элементы управления из `ui`. Состояние хранится в сигналах, и при изменении сигнала обновляется только то, что его читает.

```go
func Root(cx *core.Scope) core.Node {
	count := core.NewSignal(cx, 0)
	return core.View{Style: core.Style{Padding: core.All(24), Gap: 12}, Children: []core.Node{
		core.Text{ContentFunc: func() string { return fmt.Sprintf("Pressed %d times", count.Get()) }},
		ui.Button{Text: "Press me", OnPress: func() { count.Update(func(n int) int { return n + 1 }) }},
	}}
}
```

То же приложение можно написать на TSX и оформить классами Tailwind ([приложения на TSX](tsx.md)).

## Как это работает

Приложением управляет движок на Go: реактивный граф, стили, раскладка flexbox и grid, а также подготовка текста. Каждое обновление создаёт один пакет изменений, а тонкий бэкенд применяет его к нативным представлениям платформы. Анимация выполняется по часам кадров платформы, поэтому ничего не фиксируется раз в кадр.

| Платформа | Чем отрисовывает |
| --- | --- |
| iOS | UIKit и CoreText |
| Android | Android Views |
| macOS | AppKit и CoreText |
| Windows | Direct2D и DirectWrite |
| Linux | GTK 4, Pango и Cairo |
| Веб | WebAssembly и элементы DOM |

Все целевые платформы собираются на Mac с Go; для iOS также нужен Xcode. Инструмент `nsgo` создаёт, запускает, тестирует и упаковывает приложения.

## Состояние проекта

NSGo находится на раннем этапе: 0.1.0 — его первый выпуск, API пока не стабилен, а то, чего не хватает, описано в [плане развития](https://github.com/nsgo-dev/nsgo/blob/main/docs/roadmap.md). Он переносит дизайн [Native Shell](https://github.com/longbridge/nsh) на Go.
