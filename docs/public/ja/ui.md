これらは `ui` が提供するコンポーネントで、NSGo の見た目とテーマに従います。このリファレンスでは、アプリで最初に使うことになるコンポーネントから解説しています。各ページは最短の例から始まり、構成要素、状態、アクセシビリティへと進みます。ギャラリーでは、まだここに個別ページがないものも含めてすべてのコンポーネントを取り上げています。

[ギャラリー](https://nsgo.dev/gallery/)では、すべてのコンポーネントのデモをブラウザ上で動かせます。

## アクション

- [Button](ui/button.md): プレーンまたはアクセントカラーのプッシュボタンと、アイコンボタン。

## テキストと入力

- [Text](ui/text.md): 段落、スパン、リンク、フォント、ドキュメントテキスト。
- [Input](ui/input.md): プラットフォームのテキストフィールド（制御・非制御の両対応）。
- [Checkbox](ui/checkbox.md): チェック済み、未チェック、不確定状態を持つチェックボックス。
- [Switch](ui/switch.md): オンまたはオフの状態を持つ設定スイッチ。
- [Select](ui/select.md): リストから 1 つの値をポップアップまたはシートで選択するコンポーネント。
- [Slider](ui/slider.md): トラック上の 1 つの値または範囲を選択するスライダー。

## コレクション

- [List](ui/list.md): 任意の数の行を表示範囲のみ構築し、選択やアクティベーションに対応するリスト。
- [Scroll](ui/scroll.md): ページング、スナップ、ズーム、リフレッシュに対応したプラットフォームのスクロールビュー。

## ナビゲーション

- [Tabs](ui/tabs.md): タブリスト、セグメンテッドコントロール、システムタブバー。

## オーバーレイ

- [Dialog](ui/dialog.md): モーダルサーフェス、シート、システムアラート。
- [Menu](ui/menu.md): トリガーから開くメニュー、コンテキストメニュー、およびメニュー項目。

## その他

残りのコンポーネントはギャラリーで取り上げています。テーブル、チャート、コードエディター、リッチテキスト、ターミナル、ドック、コマンドパレット、カラー・日付・絵文字ピッカー（`ui.EmojiPicker`）、トーストなど、それぞれにデモがあります。

`base/terminal.View` は URL を開くのと同様に、Command+クリック（Windows と Linux では Control+クリック）で既存のローカルパスを開きます。相対パスはシェルの OSC 7 作業ディレクトリを基準とし、ローカルシェルが作業ディレクトリを報告していない場合は `terminal.Options.Dir`、それも未設定の場合はホームディレクトリを使用します。空白を含むファイル名はクォートで囲んでください。リモートのディレクトリオーソリティや、ローカルディレクトリを報告しない接続はローカルファイルとして解決されません。ファイルとフォルダーは `Scope.OpenFile` を使用し、URL リンクは引き続き `Scope.OpenURL` と組み込みホストの URL ハンドラーを経由します。

`base/terminal.View` はデフォルトでプログラムによるクリップボードの読み取りと書き込みを拒否します。アプリがそれらを許可する場合にのみ `AllowClipboardRead` と `AllowClipboardWrite` を設定してください。その場合でも、要求元ビューの `AccessClipboard` は引き続き適用されます。TSX の `Terminal` でも同じ props が利用でき、セッションを再起動せずに変更できます。アプリ側で同意 UI を提供してください。ユーザーによる明示的なペースト操作では、これとは独立して Kitty クリップボードプロトコル（モード 5522）を使用するプログラムにテキスト／PNG スナップショットが提供され、そのワンタイムパスワードではそのスナップショットのみを読み取れます。このモードに対応していないプログラムには通常のブラケット付きペーストテキストが届きます。クリップボード画像の利用可否はプラットフォームのクリップボードサービスに依存し、X11 のプライマリセレクションは公開されません。
