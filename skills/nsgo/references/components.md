# Choosing components

Use `ui`'s component whenever one exists: it is `base`'s control with NSGo's look, following the theme. Reach for `base` only for a look of your own, and for `core` for primitives. Check the `ui` and `base` packages in the module directory (`go list -m -f '{{.Dir}}' github.com/nsgo-dev/nsgo`) before building a control, and `examples/gallery` for each one's demo.

| Need | Use |
| --- | --- |
| Box, text, image, icon | `core.View`, `core.Text` with `core.Span` runs, `core.Image`, `core.Icon` with icons from `icons/lucide`; `ui.Textf` for text from a signal in a size, weight and color |
| Buttons | `ui.Button` (`ButtonPrimary`, `ButtonSecondary`, `ButtonOutline`, `ButtonGhost`), `ui.IconButton` with a `Label` for screen readers that also shows as its tooltip (`Tooltip` overrides it), `ui.ToggleButton`, `ui.ToggleGroup`, `ui.HoldToConfirm`, `ui.Link` (`Style.Color` colors its text and hover underline) |
| Text fields | `ui.Input` (controlled with `Value` and `OnChange`, `Multiline`, `Masked`), `ui.NumberInput`, `ui.OtpInput`, `ui.TagInput`, `ui.FormField` for a label and message |
| Choices | `ui.Switch`, `ui.Checkbox`, `ui.Radio` in a `ui.RadioGroup`, `ui.Select[T]` with `ui.Option[T]`, `ui.Combobox`, `ui.Slider`, `ui.Rating` |
| Dates, times, colors and emoji | `ui.DatePicker`, `ui.Calendar`, `ui.TimeField`, `ui.ColorPicker`, `ui.EmojiPicker` (`base.EmojiPicker` for custom styling; multi-language search, categories, skin tones; `base.EmojiPickerRef` focuses, reads or sets the query and jumps categories) |
| Scrolling and long data | `ui.ScrollView` or `core.Scroll`; `ui.List` or `core.List` for rows built only in view; `core.NewCollection` behind them |
| Tables, trees and charts | `base/datatable` for large tables, including `MultiSelect`, controlled `SelectedRows`, `LabelFunc` and `CellTooltip` (a `ui.Tooltip` inside `RenderCell` never shows), `base.Table` for small ones, `ui.Tree`, `base/plot` for charts |
| Navigation | `base.NewNav` with `ui.NavPage` and `ui.NavHeader` (the system's header on iOS and Android), `ui.Tabs[T]`, `ui.Sidebar`, `ui.SidebarShell`, `ui.TabShell` (a bottom bar at every width; the system's on iOS and Android when every tab has a `SystemIcon` or an SVG `Icon`), `mobile.TabBar` for the system tab bar, `ui.Breadcrumbs`, `ui.Pagination`, `ui.Stepper` |
| Overlays | `ui.Dialog`, `ui.AlertDialog`, `cx.ShowAlert` for the system's alert, `ui.Sheet`, `ui.Popover`, `ui.HoverCard`, `ui.Tooltip`, `ui.Toaster` for toasts |
| Menus and commands | `ui.Menu` with `ui.MenuItem` and `ui.Submenu`, `ui.ContextMenu`, `ui.CommandDialog`, `ui.Toolbar` |
| Disclosure and layout helpers | `ui.Accordion`, `ui.Collapsible`, `ui.Carousel`, `ui.Spacer`, `ui.HStack`, `ui.Wrap`, `ui.Settings` and `ui.FormSection` for settings pages |
| Progress and status | `ui.Progress`, `ui.ProgressRing`, `ui.Spinner`, `ui.Skeleton`, `ui.Meter`, `ui.Badge`, `ui.Avatar`, `ui.AvatarGroup` |
| Documents and editors | `base/textview` for streaming Markdown with formulas (`base/formula`) and Mermaid diagrams (`base/diagram`), `ui/editor` for code, `ui/richeditor` for rich text, `ui/diff`, `base/terminal` |
| Complex views | `ui/chat` for conversations, `ui/flow` for flow diagrams, `ui/commitgraph`, `base/dock` for dockable panels |
| Web content and media | `core.WebView`, `core.Video`, `core.Canvas` for 2D drawing and shaders |
| Platform services | `cx` methods and `core.Env` (clipboard, storage, secrets, links, pickers, speaking, notifications, haptics, permissions, biometrics, Sign in with Apple, in-app purchases through `cx.Purchase`, OAuth sign-in through `cx.AuthSession` rather than a web view, `cx.SetWebCookies` to carry a sign-in into web views, `cx.WebCookies` to read one out and `cx.ClearWebsiteData` to sign out of every site), `desktop` for windows, trays and menus, `mobile` for phones, `widget` for widgets and Live Activities, `updater` for updates |

Use `ReadClipboardItems` and `WriteClipboardItems` to save and restore native clipboard data on macOS and Windows. `ClipboardChangeCount` detects a new copy ([services](https://nsgo.dev/docs/services.md#alerts-and-the-clipboard)).

## Using them well

- Give a text attachment's span `Content` for selections to copy in its place; empty content omits it ([text](https://nsgo.dev/docs/text.md#runs-and-links)).
- For diagrams in an app's palette, return `base/diagram.View` with `ThemeFunc` from the text view's `RenderDiagram` callback and build its `diagram.Theme` from `ui.ColorsOf(cx)` inside that function ([text](https://nsgo.dev/docs/text.md#documents)).
- For formulas receiving source in chunks, use `formula.View.SourceFunc` with `Streaming` or `StreamingFunc` to hide unfinished recovery ink, and clear the flag at completion so remaining errors show; a TextView `RenderMath` callback can return that view ([text](https://nsgo.dev/docs/text.md)).
- Let `diagram.View` follow its container's width; `RenderDiagram: diagram.RenderDiagram` fits a TextView's Mermaid blocks to their viewport. Wide flowcharts can turn down while labels keep their size ([text](https://nsgo.dev/docs/text.md)).
- For terminal rendering, `Options.CursorBlink` enables the default blink; programs may override it. `View.MinimumContrast` adjusts ordinary text and `PaddingColor` takes `PaddingBackground`, `PaddingExtend` or `PaddingExtendAlways`; TSX uses `cursorBlink`, `minimumContrast` and `paddingColor` ([Terminal](https://nsgo.dev/docs/terminal.md)).
- `widget.Update` publishes the same timeline to Apple widgets and Android App Widgets. Android standalone APKs/AABs generate providers from `widgets` in YAML; use registered URL schemes for `Entry.URL` and `Style.Link`, `Image` for portable artwork, and allow background transitions to follow Android's inexact alarm schedule. [Widgets](https://nsgo.dev/docs/widgets.md).
- `base/terminal` renders Kitty RGB/RGBA/PNG images with `Options.ImageLimit` (zero: 64 MiB; negative: disabled), search colors through `Theme.Search`, `SearchText`, `SearchSelected`, `SearchSelectedText`, and Alt/Option-click cursor movement in an active OSC 133 command input. Apps provide shell integration markers; NSGo installs no scripts. [Terminal](https://nsgo.dev/docs/components.md#terminal)
- On Windows and Linux, `cx.AuthSession` with `AuthSessionOptions.Scheme` needs the same `url_schemes` declaration in `nsgo.yaml`; leave `Scheme` empty for loopback. Keep PKCE and state validation in the app, give browser sessions a timeout or cancel button, and use distinct callback paths for simultaneous sessions.
- `base/terminal` runs browser sessions through `Options.Conn` (`io.ReadWriteCloser`); adapt WebSocket messages to a continuous binary stream, own its server/control protocol, and close the session with the scope. Browser builds embed libghostty-vt Wasm and need no native library or Zig installation. [Terminal](https://nsgo.dev/docs/terminal.md).
- Use `ui.ShellTab.TextFunc` and `ui.TabShell.LabelFunc` for a changing tab title and bar name, and set `Edge` (`mobile.TabBarLeading`, `mobile.TabBarTrailing` or `mobile.TabBarAutomatic`, reading `core.Env.VerticalBarEdge`) on `mobile.TabBar` or `ui.TabShell` to place the bar vertically along an edge.
- Set `tabBarBackground`, `tabBarIdle`, `tabBarSelected` and `tabBarIndicator` as Android `mobile.TabBar` palette roles. A custom palette uses `Accent` for selected content by default.
- Set `mobile.TabBarItem.Badge` to a `mobile.TabBadge` with `Text` or `Dot`. Update it through `ItemsFunc`, or give `ui.ShellTab.Badge` a getter. Assert a native item with `nsgotest.View.TabBadge(index)`.

- For a marker band behind wrapped text, give a `core.Span` a `Background` and `BackgroundInsetTop`, such as `core.Pct(62)` ([text](https://nsgo.dev/docs/text.md#runs-and-links)).
- Set `core.SaveOptions.Start` to an existing absolute folder to start the system save dialog there on macOS, Windows, Linux and iOS. [Files](https://nsgo.dev/docs/services.md#files).
- Set `core.SaveOptions.Accept` to check the destination before a desktop or Android save writes it. A refusal leaves the destination untouched. macOS, Windows and Linux's in-process GTK chooser let the user choose another path and report the refusal to the completion callback if they cancel. Android and the Linux desktop portal report the refusal immediately. [Files](https://nsgo.dev/docs/services.md#files).
- `Drawing.DrawAtlas` draws tiles from one image with source `Bounds`, per-tile `RSXform` transforms, and optional opacity factors ([canvas](https://nsgo.dev/docs/canvas.md)).
- `core.Canvas.Draw` runs again when a signal it reads, its size or the available fonts change; `cx.RegisterFont` updates its glyphs and `Drawing.TextMetrics` once the font loads, including asynchronously on the web ([canvas](https://nsgo.dev/docs/canvas.md)).
- `cx.NewOffscreenImage` creates a retained `core.OffscreenImage` cached across frames until `Invalidate` or `Resize` is called, whose `Source()` draws via `Drawing.DrawImage`, `Drawing.DrawImageIn`, `Drawing.DrawImageFrom` or `core.Image`, and releases automatically on scope disposal.
- Keep scaled pixel art sharp with `Drawing.SetImageSmoothing(false)` for Canvas image draws and `DrawAtlas`, or `Sampling: core.ImageSamplingNearest` on Image. In TSX set `ctx.imageSmoothingEnabled = false` or `sampling="nearest"` ([canvas](https://nsgo.dev/docs/canvas.md), [images](https://nsgo.dev/docs/images.md)).
- `Drawing.DrawVertices` draws a triangle list from one image. Each `core.CanvasVertex` gives a canvas position, image-point texture coordinates and an optional color. Record the drawing again to change its vertices.
- Use `DrawTintedImage`, `DrawTintedImageIn` or `DrawTintedImageFrom` to multiply a canvas image by an sRGB color and opacity before compositing; HarmonyOS tints only images from bytes or the app's resources, not yet checked on a device. In TSX use `drawTintedImage` ([canvas](https://nsgo.dev/docs/canvas.md)).
- Use `core.ShaderEffect` or `core.ScreenEffect` to shade views with WGSL, and `core.ShaderTransition` or `core.ScreenTransition` to shade a change of value. Android captures views from Android 10 with external texture support ([canvas](https://nsgo.dev/docs/canvas.md)).
- Show frames the app decodes or renders (video, emulators, previews) in a `core.Image` with `ImageSource{Pixels: frame, Version: n}`, bumping `Version` after writing each frame into the same `*image.RGBA`, and filter such a frame on the GPU by passing the same source in a `core.Shader`'s `Images`; never encode a PNG per frame ([images](https://nsgo.dev/docs/images.md)).
- Place `core.Video` beside app-drawn captions in `mobile.PictureInPicture.Children` on iOS. Start the outer session and forward its play, pause and skip callbacks to the video. [Picture in Picture](https://nsgo.dev/docs/picture-in-picture.md)
- Check `cx.Env().HasWebView()`, `CanTakePhoto()` and `CanRecognizeSpeech()` before offering those features on tvOS. The platform refuses unavailable web views and pickers, and clipboard reads return no content. [Platform services](https://nsgo.dev/docs/services.md)
- Drive a native `core.WebView` through its `core.Ref` (`Reload`, `GoBack`, `GoForward`); app-owned history entries keep their `core.AccessWebSchemes` exemption, while new page-created navigations remain restricted. On Windows, `OnNavigationStateChange` also follows same-document history and titles.
- Call `cx.RequestOrientation(core.OrientationLandscape)` in the full-screen view's scope on iOS, Android or the web. On the web, enter full screen with `desktop.ToggleFullScreen(cx)` in the press that opens that scope. Disposal restores the previous policy, and `app.Orientation` records the request in tests. [Interface orientation](https://nsgo.dev/docs/services.md#interface-orientation)
- Use `audio.NewOutput` to play decoded or synthesized PCM on macOS, iOS, Android, Windows, Linux and the web. Its `Render` callback runs on the audio thread and must avoid blocking, allocations and graph access ([PCM audio](https://nsgo.dev/docs/services.md#pull-pcm-audio)).
- Set `core.WebView.Mobile` (TSX `mobile`) to show a site's phone layout on Windows, macOS and Linux, with mouse drags and wheel or trackpad swipes reaching the page as touches; phones and the web ignore it ([Components](https://nsgo.dev/docs/components.md)).
- Use `core.WebView.OnOpenWindow` to handle page requests on Apple, Windows and Linux. Inspect `UserInitiated` before opening the URL. The view suppresses the popup. [Components](https://nsgo.dev/docs/components.md)
- Linux WebView needs WebKitGTK and a working bubblewrap sandbox. If NSGo logs AppArmor's user namespace restriction and shows a placeholder, follow the [Linux troubleshooting steps](https://nsgo.dev/docs/debugging.md#linux-web-views).
- On macOS, iOS and Linux, `WebView.OnNavigationStateChange` also reports same-document URL, history and title changes.
- Set `core.Video.Headers` for headers such as `Referer` on Android video requests and for direct HTTP video files on Linux, macOS, iOS and tvOS. [Components](https://nsgo.dev/docs/components.md)
- `core.Video.RateFunc` changes playback speed. Use `VideoInfo.RateChangeable` from `OnLoad` to decide whether to offer a speed control. Linux's fallback player runs at 1× ([Components](https://nsgo.dev/docs/components.md)).
- A transparent `core.Video` needs HEVC with alpha (`.mov`) on macOS (iOS unchecked) and VP9 with alpha (WebM) on Linux. On macOS, iOS, Windows and Linux a local clip whose alpha cannot be kept reports `OnError` with a `*core.MediaError` whose `Reason` is `core.MediaErrorAlphaUnsupported` (Windows refuses every clip with alpha until Media Foundation's alpha output is checked), so check `Reason`, not the message, to fall back to the app's own decoder; Android, the web and remote URLs play it as the decoder outputs it, possibly opaque ([Components](https://nsgo.dev/docs/components.md)).
- On macOS, iOS and tvOS, use `core.Video.AudioSource` for the separate audio URL of a finite clip. The player seeks both tracks together, and `Headers` also applies to direct HTTP audio files.
- A component's look comes from its `Variant`, a type of its own whose zero value is the default (`ui.ButtonVariant`), and a few take `Size` (`ui.SizeDefault`, small or large). Do not fake a variant with styles over the default.
- Bind an element's screen-reader actions with `AccessibilityActionsFunc` on a `core.View` or `core.Input`. Give a translated action the same `Name`.
- For validation in `base` controls, pass `Invalid: rejected.Get`; style it with `aria-invalid:` classes or `Style.AriaInvalid`. Custom controls pass it to their actual input or root and use `core.PartStates.Invalid` on decorative parts to avoid duplicate accessibility state.
- `ui.Button` uses larger touch targets on phones and tablets; use `Style: core.Style{Width: core.Pct(100)}` for a full-width action or set `Height` for another height. `ui.OtpInput.Size` sets both cell dimensions in points, and `CellWidth` and `CellHeight` override either one. Use `TextStyle`, `CornerRadius` and `CaretHeight` for the cell and caret. `ui.FormRow` and `ui.FormField` have a 48-point touch minimum.
- Controlled controls take a getter and a setter: `Value: name.Get, OnChange: name.Set`, `Checked: on.Get`, `Open: dialog.Get, OnOpenChange: ...`.
- `ui.Button` offers `ButtonTinted` and `ButtonDanger`. Set `TextStyle` for label typography and `BusyLabel` or `BusyLabelFunc` for a message beside the busy spinner.
- For Shift-press range selection, `base.Checkbox` and `ui.Checkbox` take `OnChangeEvent func(checked bool, press core.PressEvent)` in place of `OnChange`; TSX receives `{ checked, press }`. The app still owns the value ([Checkbox](https://nsgo.dev/docs/ui/checkbox.md)).
- Use `ui.Slider.MinFunc`, `MaxFunc` and `StepFunc` for changing ranges and steps; `base.Slider.Min`, `Max` and `Step` already take getters. This keeps focus and an active drag mounted.
- `ui.Dialog` and `ui.AlertDialog` take `Style` and `StyleFunc` for their surface; use `StyleFunc` for colors that follow the theme or other signals, merged after `Style` on both centered dialogs and sheets.
- Give `ui.Sheet` a `Label` or `LabelFunc` for its accessible dialog name and `TestID` for its panel. Set `CloseOnSwipe` to request `OnClose` after a downward swipe; the app still updates `Open` ([Sheets](https://nsgo.dev/docs/ui/dialog.md#sheets)).
- Style the `ui.FormSection` surface with `CardStyle` and `CardStyleFunc`. Set `FormRow.LeadingWidth` for a custom `Leading` node so its divider aligns with the title, or change the icon slot with `TileSize`. Style text with `TitleStyle` and `DetailStyle`.
- Style every toast in a stack with `ui.Toasts.Style` and `StyleFunc`, or one with `ui.ToastContent.Style` and `StyleFunc`. Per-toast styles override the stack, and each `StyleFunc` follows its signals.
- Give each control a label screen readers hear (`Label`, or the button's text); icon-only buttons need one. An input's `Placeholder` is a separate hint, exposed on macOS, iOS and Linux for single-line, masked and multiline fields without a second focus stop for the drawn placeholder; keep its `Label` meaningful when that hint changes or clears.
- Use `TextFunc` on `ui.Button`, `ui.Checkbox`, `ui.MenuItem` and `ui.AlertAction` for text that follows locale or state. The text names the control unless a button or checkbox has its own label.
- Use `LabelFunc` on sliders, tabs, switches, progress bars, popup triggers and selects for a spoken name that changes while the control stays mounted. `ui.Option.LabelFunc` changes the choice's text in tabs, selects and comboboxes.
- `ui.NavPage` and `ui.NavHeader` draw the system's own header and back gesture on phones, and `NavHeader` with its back button elsewhere, an Apple Watch included; do not build a header of views.
- `ui.Menu` and `ui.Select` open beside their trigger on any device, or as a sheet when their `Presentation` asks; choose it explicitly instead of switching by device.
- `core.Ref` focus, blur, scroll and zoom requests are dropped while the element is in unplaced `core.Holder` content, or when it leaves the tree before the commit; showing the content again does not replay them, so ask again once it is placed.
- Web canvases in a zoomed `core.Scroll` or scaled `Style.Transform` / `AnimatedStyle` replay at the cumulative scale once it rests, up to four times the screen's pixel ratio (drawing only the visible slice past 4096 × 4096 pixels), without rerunning `Draw` ([canvas](https://nsgo.dev/docs/canvas.md)).
- Application-menu editing roles go to the focused editor before `OnSelect`. On macOS, Undo and Redo follow its history and Cut its selection, even while inactive; with no editor the fallback remains enabled ([services](https://nsgo.dev/docs/services/#lifecycle)).
- Use `mobile.Immersive(cx, on)` for the window or set `StatusBar.Immersive` on a page or dialog. Read its system insets from `cx.Env().SafeArea()`.
- A hidden Windows or Linux title bar keeps the application menu accessible through Alt alone, F10 and Alt plus a top-level label’s first letter or digit; app bindings still take precedence, and Escape restores keyboard focus ([services](https://nsgo.dev/docs/services.md)).

Formulas also render on watchOS. Their font loader retains its own parsed font and byte copy; simulator memory readings do not establish a physical watch's available headroom. Measure the app on its target watch before budgeting memory ([text](https://nsgo.dev/docs/text.md)).

Terminal path links use the shell’s OSC 7 directory, or `terminal.Options.Dir` for a local shell before its first directory report. Quote paths with spaces; modifier-click opens existing local files/folders through `Scope.OpenFile`, and URL links use `Scope.OpenURL`. Remote authorities are not local paths. [Components](https://nsgo.dev/docs/ui.md)

Mermaid diagrams use `diagram.View.Icons` to map names such as `"fa:fa-car"` to `*core.SVG` documents. Image nodes share the canvas image loader (HTTP(S), files and `asset:`); `constraint: "on"` preserves their proportions. A custom `RenderDiagram` callback can return a `diagram.View` with the app's icon map ([text](https://nsgo.dev/docs/text.md)).

Android Live Activity actions reach `widget.OnAction` without opening the Activity while the posting engine runs; keep that engine alive for actions, and use the notification content tap to reopen the app. [Live Activities](https://nsgo.dev/docs/live-activities.md#presses).

`widget.Button` calls `widget.OnAction` from iOS 17 and macOS 14; register it before `nsgo.Run`, handle `Activity == nil` for a widget, and publish `widget.Update` before returning. See [Widgets](https://nsgo.dev/docs/widgets.md#buttons).

`Text.AdjustsFontSizeToFit` shrinks formulas and other font-relative attachments with the text, respecting `MinimumFontScale`; explicit point sizes and padding stay as authored ([text](https://nsgo.dev/docs/text.md)).

Use `mobile.OpenedURL(cx)` for an Android invocation or a whole-page web address available before rendering; it follows later links and browser address changes. Declare Android HTTPS hosts with `app_links` and serve their Digital Asset Links association files; embedded hosts own their filters. Keep authentication callbacks consumed before ordinary incoming-link handling. [App Links](https://nsgo.dev/docs/building.md#android-app-links).

`base/terminal.View` and TSX’s `Terminal` default `AllowClipboardRead` and `AllowClipboardWrite` to false. Apps own consent UI; program requests also need the view’s `AccessClipboard`. Explicit user paste can independently offer a copied text/PNG snapshot to Kitty programs, with a one-use token limited to that snapshot. [Components](https://nsgo.dev/docs/ui.md)
