# purego

This is the `github.com/ebitengine/purego` v0.11.3 subset used by NSGo so Android arm64 can use the same call and callback machinery with `CGO_ENABLED=0`. Upstream purego's Android loader still requires cgo (tracked in `ebitengine/purego#572`); the Android files here import bionic's `libdl.so` and `libc.so` symbols (including `__errno`) through Go dynamic imports and keep desktop platforms on upstream purego. Using `CGO_ENABLED=0` with `fakecgo` on Android requires Android 10 (API level 29) or later. The source is distributed under the upstream Apache-2.0 license in [LICENSE](LICENSE).
